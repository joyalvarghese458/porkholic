# Browser icon

Generated using built-in image_gen with the transparent PorkHolic logo as a reference. Master: `_assets/favicon-pig.png`. Production assets: `src/app/favicon.ico` (16, 32, 48, 64px frames), `src/app/icon.png` (192px), `src/app/apple-icon.png` (180px), and `public/favicon-32.png`. Regenerate using `node scripts/generate-favicon.mjs`, also invoked by `npm run images`.

Prompt:

Use case: logo-brand. Create a browser favicon derived from the reference PorkHolic pig mascot. Render ONLY a simplified close-up of the same cheerful pink pig HEAD with its two ears, closed happy crescent eyes, tilted oval pink snout with two black nostrils, and smiling black mouth. Retain the familiar pig's pink color and strong black outlines. Square icon composition, face fills almost the entire square with about 5 percent even transparent margin and both ears entirely inside the image. Simplify shading to flat pink fills and at most one darker pink accent, thicker clean bold black contours for perfect legibility at 16x16 and 32x32 pixels. No paws, no body, no curved baseline, no lettering or words, no registration symbol, no logo text, no decorative elements, no gradients, no shadow. Genuinely transparent background. Clean professional icon asset, not a photograph.
